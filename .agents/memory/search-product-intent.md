---
name: Search product intent
description: User direction on using AI and offering useful search alternatives in SignalSC
---

The user wants extensive useful AI use throughout SignalSC, especially home-page searches that return exact matches or clearly labeled related events rather than an empty result when alternatives exist.

**Why:** The user reported advertised-food events appearing in Discover while home search returned nothing, and explicitly asked to leverage AI more.

**How to apply:** Prioritize helpful discovery and recommendations while preserving the distinction between confirmed event facts, unknown details, and relaxed search conditions. Keep real-provider checks separate from automatic tests and obtain approval for new paid verification runs.

Past events must stay out of the normal Discover feed, but searching title keywords should find them so students can leave reviews and feedback.

**Why:** The user explicitly requested archive search without showing past events by default.

**How to apply:** Preserve the upcoming-only default and clearly distinguish historical search results from upcoming events. Keep historical event links and feedback attached to their original event identity.
